# FastMasseg Bot — Telegram-бот для рассылок студентам (PHP)

Удобный Telegram-бот на чистом **PHP 8+ и SQLite** для преподавателей и учебных групп. Позволяет быстро рассылать объявления, файлы, фото и альбомы студентам по группам, принимать заявки на подписку и отвечать на вопросы студентов прямо через Reply.

---

## ✨ Возможности

### 👑 Главный преподаватель (`ADMIN_ID`)
- Все возможности преподавателя.
- **Управление преподавателями**:
  - `/addteacher` — назначить нового преподавателя (по числовому ID или просто переслав его сообщение боту).
  - `/teachers` — список преподавателей и снятие статуса в один клик.
- **Резервное копирование**:
  - `/backup` — скачать актуальную копию базы данных `students.db` прямо в Telegram.
  - Автоматический ежедневный бэкап базы данных в чат главному преподавателю.

### 👨‍🏫 Преподаватели
- **Рассылки студентам**:
  - Поддержка любых типов сообщений: текст, фото, видео, альбомы (несколько фото/видео/документов), голосовые, кружки, файлы, опросы.
  - Выбор целевой аудитории: конкретная группа или все группы сразу.
  - Режимы отправки: **Обычно**, **📌 С закреплением**, **🔕 Без звука**, **⏰ Отложить** (через 1 час, завтра в 08:00 или в любое указанное время).
- **Группы**:
  - `/groups` — список групп, количество студентов, коды и готовые ссылки-приглашения (`https://t.me/<bot>?start=<код>`).
  - `/newgroup` — создание новой учебной группы.
  - Быстрая смена кода приглашения (старая ссылка перестаёт работать) и удаление пустых групп.
- **Студенты и заявки**:
  - `/requests` — модерация заявок студентов (`✅ Принять` / `❌ Отклонить`) с проверкой реального имени и фамилии.
  - `/list` — полный список студентов по группам.
  - `/find` — поиск студента по имени или фамилии.
  - `/remove` — удаление студента из рассылки.
  - `/export` — выгрузка списка всех студентов в таблицу **CSV (Excel)**.
- **История и управление рассылками**:
  - `/history` — последние 5 рассылок с отчётом о доставке.
  - `/delete` — удаление отправленной рассылки у всех студентов (в течение 48 часов).
  - `/scheduled` — просмотр и отмена запланированных рассылок.
  - `/stats` — общая статистика бота.
- **Обратная связь**:
  - Вопросы от подписанных студентов пересылаются преподавателям. Чтобы ответить студенту, достаточно ответить на сообщение бота через **Reply (Ответить)**.

### 🎓 Студенты
- Подписка по персональной ссылке учебной группы от преподавателя.
- Ввод настоящих имени и фамилии и подтверждение заявки преподавателем.
- Возможность задать вопрос преподавателю прямо в чате с ботом.
- `/stop` — отписка от рассылки.

## 🚀 Установка и запуск

### 1. Требования
- **PHP 8.0+** (CLI) с включёнными расширениями:
  - `curl`
  - `mbstring`
  - `openssl`
  - `pdo_sqlite`

### 2. Настройка `.env`
Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```
И укажите в `.env` ваши данные:
```env
TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id
TIMEZONE=Asia/Bishkek
```
> Свой Telegram ID можно узнать, запустив бота и отправив ему команду `/id`.

### 3. Запуск
Через терминал:
```bash
php bot.php
```
Или на Windows — просто запустите файл **`start.bat`** двойным кликом (он также автоматически перезапустит бота при обрыве связи).
